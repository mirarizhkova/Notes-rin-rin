# Notes RinRin — PDF Notes MVP Design

## Goal

Создать минимальное личное веб-приложение для чтения PDF и простых рукописных заметок поверх страниц.

## MVP scope

Первая версия должна уметь только следующее:

1. Загрузить PDF с устройства.
2. Показать все страницы PDF вертикальной лентой сверху вниз.
3. Позволить обычную прокрутку документа.
4. Позволить pinch-to-zoom двумя пальцами на сенсорном устройстве.
5. Иметь отдельный режим рисования, включаемый кнопкой.
6. В режиме рисования рисовать одной чёрной ручкой.
7. Иметь ластик для удаления нарисованных штрихов.
8. Хранить пользовательские штрихи локально на устройстве, без загрузки PDF или заметок в GitHub.

## Explicitly out of scope for v0.1

- выбор цвета;
- выбор толщины;
- текстовые заметки;
- папки и библиотека;
- пустые страницы;
- перестановка страниц;
- аккаунты;
- серверная база данных;
- синхронизация;
- экспорт изменённого PDF;
- App Store;
- PWA/offline-installability как отдельная задача.

## Interaction model

### Reading mode

- Один палец: прокрутка страницы.
- Два пальца: масштабирование и перемещение стандартными жестами браузера.
- Рисование отключено.

### Drawing mode

- Кнопка `Draw` включает рисование.
- Один палец или стилус рисует чёрную линию поверх PDF.
- Два пальца по возможности остаются жестом масштабирования/перемещения и не создают штрихи.
- Кнопка `Eraser` переключает инструмент на удаление пользовательских штрихов.

## Rendering approach

- PDF рендерится через PDF.js.
- Каждая PDF-страница отображается в отдельном контейнере.
- Поверх визуального слоя страницы располагается прозрачный canvas для заметок.
- Canvas хранит только пользовательские штрихи; исходный PDF не изменяется.

## Local persistence

- Исходный PDF выбирается локально пользователем.
- PDF не загружается в GitHub и не отправляется на сервер.
- Штрихи сохраняются локально в браузере через IndexedDB.
- Для привязки заметок к документу используется локальный идентификатор PDF, вычисляемый из содержимого файла или устойчивой комбинации метаданных.

## Repository / hosting

- Исходный код находится в `mirarizhkova/Notes-rin-rin`.
- Для бесплатного GitHub Pages репозиторий должен быть Public.
- Публичность репозитория относится только к исходному коду. Пользовательские PDF и заметки в репозиторий не попадают.

## Success criteria

MVP считается достаточным, если на телефоне/планшете можно:

1. открыть сайт;
2. выбрать PDF;
3. читать его вертикальной лентой;
4. увеличить нужный участок жестом;
5. включить Draw и сделать чёрную пометку;
6. стереть эту пометку;
7. закрыть и снова открыть документ на том же устройстве и увидеть сохранённые штрихи.
